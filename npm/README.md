# ⚡ @sluisr/uti-cli

> **Universal Terminal Intelligence (UTI CLI)** — High-Performance Autonomous AI Coding Agent for DeepSeek API & Local LLMs.

[![npm version](https://img.shields.io/npm/v/@sluisr/uti-cli?color=blue)](https://www.npmjs.com/package/@sluisr/uti-cli)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue)](https://github.com/sluisr/uti-cli/blob/main/LICENSE)

## 📦 Installation

Install globally via npm:

```bash
npm install -g @sluisr/uti-cli
```

Or run directly without installing using `npx`:

```bash
npx @sluisr/uti-cli
```

## 🚀 Usage

Once installed, simply run:

```bash
uti
```

Or execute non-interactive commands:

```bash
uti -p "Analyze this project and run all unit tests"
```

## ⚡ Features

* 🦀 **100% Pure Native Rust:** Single standalone machine binary with sub-10ms startup time and ~21 MB memory footprint.
* 🧠 **DeepSeek V4.1 Engine:** Native support for `deepseek-flash` (vision-language MoE, 1M context) and `deepseek-v4-pro` (Reasoning CoT).
* 💰 **Hybrid Intelligence (@ $0.00):** Local SLM routing (`llama-server`, `llama.cpp`, or `Ollama`) on port 8080 for free offline chat and code triage.
* 🛡️ **96%+ KV Cache Hit Rate:** Background tool compression preserving KV cache to slash API costs.
* 🖱️ **Clickable Terminal Hyperlinks:** Click any link directly to open in your default browser.
* 🌊 **Silk Wave Animations:** Smooth, 60 FPS real-time status transitions.
